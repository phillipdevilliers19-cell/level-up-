# Level Up

Personal arcade-style fitness tracker. Log workouts, earn XP, level up, unlock badges. Data stays on your phone (localStorage).

## Deploy on GitHub Pages
1. Create a repo and upload all files in this folder to the root.
2. Settings > Pages > Deploy from branch > `main` / root > Save.
3. Open `https://<your-username>.github.io/<repo>/` on your phone.
4. Add to Home Screen (Safari: Share > Add to Home Screen. Chrome: menu > Install app).

Use "Copy backup" on the Stats tab to save your progress before clearing browser data.
